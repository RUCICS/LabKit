# Leaderboard rank_all Config + Admin Quota Reset — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a configurable `rank_all` manifest field so all users are ranked across every track by default, and add an admin web button to reset all users' daily quota for a lab.

**Architecture:** `rank_all` is a `*bool` in manifest's `BoardSection`; the leaderboard backend service becomes the single source of truth for rank numbers; CLI and web use the API-provided rank directly. Quota reset works by changing today's charged submissions to a new `admin_reset` state via a new admin API endpoint backed by a DB migration and SQL query.

**Tech Stack:** Go (API, CLI), Vue 3 + TypeScript (web), PostgreSQL + sqlc

async function resetQuota(labId: string, labName: string) {
  if (!confirm(`Reset daily quota for all users in "${labName}"?\n\nThis marks today's charged submissions as free so everyone can submit again.`)) {
    return;
  }
  resetting.value = labId;
  resetError.value = null;

    alert(`Quota reset. ${data.rows_affected} submission(s) freed.`);
  } catch {
    resetError.value = 'Network error — quota reset failed';
  } finally {
    resetting.value = null;
  }
}
